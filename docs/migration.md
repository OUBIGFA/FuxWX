# FuxWX 迁移与验收

## 目标

Windows 原生重复文件清理工具，沿用 WxCleaner 的完整内容校验策略，改用 nsh 界面与后台清理任务。用户可以选择回收站或彻底删除，清理大量文件时保持界面可响应。

## 方案

使用 nsh TSX 编写界面，Rust 模块负责文件扫描、哈希、选择与清理。相比保留 Python 子进程，此方案避免同时分发 Python 与原生桥接进程；相比纯 Rust 界面，TSX 更便于持续调整布局。两种语言通过 nsh 官方模块机制连接。

- 界面：顶部目录选择和扫描，中央重复组/文件列表，底部选中统计、删除方式与进度
- 扫描：大小分组、首段 SHA-256、完整 SHA-256；后台执行，可停止
- 清理：默认回收站；永久删除需明确确认；每组保留文件；变更文件拒绝删除
- 性能：列表限制同时渲染的数据量，后台任务有界批处理，进度合并刷新
- 安全结果：清理成功、失败、取消分别计数；失败保留；回收站不降级为永久删除
